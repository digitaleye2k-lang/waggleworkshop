# Professor Pip — Waggle Workshop

A touch-friendly learning app with age modes, letters, numbers, colours, shapes, animals, dinosaurs, logo quizzes, musical instruments and a brick builder.

The site files are being added. No build tools are needed. Once uploaded, enable GitHub Pages under Settings → Pages using main and /(root).

Character art, music and video are supplied for The Waggle Workshop. Third-party brand marks belong to their owners.

## Try Professor Pip's playroom

While the standalone Waggle Workshop app is being built, six original no-login browser learning games are available through the sister project **PakTV Ghar Kids**:

**[Play Waggle Workshop × PakTV Ghar Kids](https://pakghartv.eu.cc/waggle-play.html)**

Activities: letters, counting, colours, shapes, animal-memory matching and rainbow brick building. These are complementary mini-games built for the collaboration; the full Waggle Workshop app described above has not yet been uploaded to this repository. All games run locally in the visitor's browser, with no chat, sign-up or personal profiles.
