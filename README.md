# Professor Pip — Waggle Workshop

A touch-friendly learning app with age modes, letters, numbers, colours, shapes, animals, dinosaurs, logo quizzes, musical instruments and a brick builder.

The site files are being added. No build tools are needed. Once uploaded, enable GitHub Pages under Settings → Pages using main and /(root).

Character art, music and video are supplied for The Waggle Workshop. Third-party brand marks belong to their owners.
